# Supermarket Sales Analysis Dashboard

## Project Overview

This project analyzes supermarket sales data using Power BI to identify sales trends, customer purchasing behavior, product performance, and payment preferences.

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* GitHub

## Dashboard Features

* Key Performance Indicators (KPIs)
* Total Sales Analysis
* Sales by City
* Product Line Analysis
* Customer Demographics
* Payment Method Analysis
* Monthly Sales Trends
* Interactive Slicers and Filters

## Key Business Objectives

* Evaluate overall sales performance.
* Compare sales across cities and product lines.
* Analyze customer types and gender-based purchasing patterns.
* Identify preferred payment methods.
* Explore monthly sales trends and business performance.

## Key Insights
* City-wise Sales Performance: Naypyitaw recorded the highest sales among the three cities.
*Product Line Performance: Food and Beverages was the highest-performing product line by sales.
*Customer Analysis: Member customers generated slightly higher sales than Normal customers
